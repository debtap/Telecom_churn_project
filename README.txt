TELECOM CUSTOMER CHURN - PYTHON MINI PROJECT

Business scenario
A telephone and internet service provider wants to understand why customers leave.
You are working as a junior data analyst. Your task is to explore customer details,
service usage, contract type, billing, support interactions and churn status.

Files
1. telecom_customer_churn.csv - 100 synthetic customer records.
2. telecom_churn_analysis.py - 20 worked examples using NumPy, Pandas,
   Matplotlib and Seaborn.

Libraries required
pip install numpy pandas matplotlib seaborn

How to run
Keep the CSV and Python file in the same folder.
Open a terminal in that folder and run:
python telecom_churn_analysis.py

Dataset fields
customer_id, gender, senior_citizen, partner, dependents, tenure_months,
phone_service, multiple_lines, internet_service, online_security, tech_support,
contract, paperless_billing, payment_method, monthly_charges, total_charges,
support_tickets, late_payments, churn.

Teaching restrictions
The examples use only NumPy, Pandas, Matplotlib and Seaborn.
No explicit loops, no if-statements and no user-defined functions are used.
Vectorized operations and built-in library functions are used instead.

Suggested classroom flow
1. Understand the business problem and dataset.
2. Inspect and clean missing values.
3. Use NumPy for numerical summaries and percentiles.
4. Use Pandas for filtering, calculated columns, grouping and cross-tabulation.
5. Use Matplotlib and Seaborn for visual analysis.
6. Discuss business actions: improve onboarding, review month-to-month plans,
   address support issues and identify customers needing proactive outreach.

Important
This is a synthetic teaching dataset. It is not real customer information.
The churn patterns are illustrative and should not be treated as proof of causation.
